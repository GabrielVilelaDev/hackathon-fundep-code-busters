## [0.1.0] - 2025-10-09

### Added
- Initial release of Design System Library
- Core components:
  - Button component with multiple variants (default, destructive, outline, secondary, ghost, link)
  - Input component with various types support
  - Card component with header, content, and footer subcomponents
- Theme system with design tokens
  - Color tokens for light and dark modes
  - Spacing, typography, and border radius tokens
- Tailwind CSS configuration with custom theme
- TypeScript support with full type definitions
- Storybook documentation for all components
- Jest and React Testing Library setup
- Test coverage for all components
- ESLint and Prettier configuration
- Vite build configuration for library output
- README with installation and usage instructions
- MIT License

### Documentation
- Comprehensive Storybook stories for each component
- Introduction and getting started guide
- Component API documentation
- Accessibility guidelines
- Design tokens documentation

### Testing
- Unit tests for Button component
- Unit tests for Input component
- Unit tests for Card component
- Test coverage threshold set to 80%
