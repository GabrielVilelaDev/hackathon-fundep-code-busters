# Design System Library

Welcome to our Design System Library! This is a comprehensive collection of reusable, accessible React components built with modern technologies.

## 🎯 Overview

This design system is built with:

- **React** - Modern React 18 with hooks
- **TypeScript** - Type-safe development
- **Tailwind CSS** - Utility-first CSS framework
- **Shadcn/UI** - Beautiful, accessible component primitives
- **Radix UI** - Unstyled, accessible components

## 🚀 Getting Started

### Installation

```bash
npm install @myorg/design-system
```

### Basic Usage

```tsx
import { Button, Card, Input } from '@myorg/design-system'
import '@myorg/design-system/dist/style.css'

function App() {
  return (
    <div>
      <Button>Click me</Button>
      <Input placeholder="Type here" />
    </div>
  )
}
```

## 📦 Components

### Available Components

- **Button** - Versatile button with multiple variants
- **Input** - Text input with validation support
- **Card** - Container for grouping content

## 🎨 Design Tokens

Our design system is built on a foundation of design tokens that ensure consistency across all components.

### Colors

We use a semantic color system with light and dark mode support:

- **Primary** - Main brand color
- **Secondary** - Supporting color
- **Accent** - Highlight color
- **Destructive** - Error and danger states
- **Muted** - Subtle backgrounds and text

### Spacing

Consistent spacing scale: `xs`, `sm`, `md`, `lg`, `xl`, `2xl`, `3xl`

### Typography

Font sizes: `xs`, `sm`, `base`, `lg`, `xl`, `2xl`, `3xl`, `4xl`

## ♿ Accessibility

All components follow WCAG 2.1 AA guidelines:

- Keyboard navigation support
- Screen reader friendly
- Proper ARIA labels
- Focus management

## 📝 Best Practices

### When to use this Design System

Use components from this library when:

- Building new features
- Ensuring consistency
- Need accessible components
- Want type-safe props

### Customization

Components are designed to be customizable:

```tsx
// Using className for custom styles
<Button className="my-custom-class">Custom Button</Button>

// Using variants
<Button variant="destructive" size="lg">Large Delete Button</Button>
```
